---
description: 하루 루틴 — 분석(주 1회) → 승인 확인 → 실행 → 요약
---

1. `python main.py daily --dry-run` 을 실행해 오늘 상황을 본다 (분석이 7일 넘었으면 자동으로 다시 분석)
2. **analyst** 서브에이전트로 새 매수 후보와 투자논리 점검 필요 종목을 요약한다
3. 승인 대기 후보가 있으면 사용자에게 승인 여부를 묻는다 (직접 approve 하지 않는다)
4. 사용자가 진행하라고 하면 **executor** 서브에이전트로 `python main.py execute` 를 실행한다
5. 마지막에 총 평가금액, 시드 대비 수익률, 오늘 체결, 알림을 5줄 이내로 정리한다
